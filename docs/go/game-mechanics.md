# 游戏机制（Go 版）

## 法律

- **继承法**：长子继承、幼子继承、选举继承、公开选举
- **王权**：低王权、中王权、高王权（等级 0-2）
- **性别法**：男系继承、男女皆可继承、绝对平等继承

## 派系

派系根据封臣对领主的好感与不满度形成。当满足条件时，派系会发出最后通牒或直接叛乱。

## 阴谋

包含谋杀、绑架、伪造把柄、拉拢、引诱、伪造宣称等类型。阴谋有进度与隐秘度，可能成功、败露或持续进行。

## 外交

- 同盟、互不侵犯、附庸、贸易协定、情报共享、联姻
- 好感度影响外交操作成功率
- 宣战需要宣战理由与足够威望

## 战争

- 军队有补给与士气
- 围城需要时间推进
- 战争疲劳过高会限制宣战
- 支持白和与强制执行

## 经济

- 领地提供月入与征召兵力
- 宴会、发展、招募精锐需要花费金币
- 破产时自动解散军团

## 内阁

可任命首相、元帅、总管、间谍总管、宫廷神甫
- 每个职位可分配任务（内政外交、伪造宣称、训练将领、强化控制、催收税赋等）
- 任务影响经济、外交、控制、情报等属性
