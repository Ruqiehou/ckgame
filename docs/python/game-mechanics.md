# 游戏机制（Python 版）

## 法律

- **继承法**：长子继承、联邦分割、选举君主、家族长老、幼子继承
- **王权**：自治王权、有限王权、高度王权、绝对王权
- **性别法**：男系继承、男系优先、绝对双系、女系继承

## 派系

派系根据封臣对领主的好感与不满度形成。当满足条件时，派系会发出最后通牒或直接叛乱。

最后通牒需要君主回应：

- **AI 君主**：派系实力压过君主时接受诉求（独立/降王权/拥立新君/改革让步），否则拒绝并立即以对应开战理由爆发叛乱
- **玩家君主**：通牒挂起为待回应事件，可通过 `respond_ultimatum` 动作（或 TUI 弹出菜单）接受或拒绝；通牒挂起期间派系不会自动叛乱

## 阴谋

包含谋杀、绑架、伪造把柄、拉拢、引诱、伪造宣称等类型。阴谋有进度与隐秘度，可能成功、败露或持续进行。

## 外交

- 同盟、互不侵犯、联姻、停战
- 好感度影响外交操作成功率
- 宣战需要宣战理由与足够威望

## 战争

- 军队有补给与士气
- 围城需要时间推进
- 战争疲劳过高会限制宣战
- 支持白和与强制执行

## 经济

- 领地提供月入与征召兵力
- 宴会、发展、招募精锐需要花费金币
- 破产时自动解散军团
